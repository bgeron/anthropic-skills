# Agent Skills — de-clauded

This repository is a fork of https://github.com/anthropics/skills/ containing Anthropic's example agent skills.

## De-clauded

There exist agents besides Claude Code. So the skills in this fork refer to the agent as "the agent", and not as "Claude", because that would probably give other models an identity crisis. We don't need no identity crises.

Also, at the time of forking, everything that was not clearly licensed under an OSI open source license was removed.

Original README: https://github.com/anthropics/skills/blob/main/README.md
